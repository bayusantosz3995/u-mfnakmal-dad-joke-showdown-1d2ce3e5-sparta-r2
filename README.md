# Dad Joke Showdown

A one-line dad joke about a father's first 10K run: a concrete setup with real numbers (10K, 52 minutes, age 58, 3 hours of bragging) and a sharp, closed punchline. Run `main.py` to write the entry to `entry.txt`.
